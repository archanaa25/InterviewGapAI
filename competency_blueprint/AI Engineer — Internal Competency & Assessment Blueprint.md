# AI Engineer — Generative AI, RAG & Agentic Systems

## Role Overview

We are looking for an AI Engineer to design, build, evaluate, and deploy production-ready AI applications powered by Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), and agentic AI systems.

The ideal candidate combines strong Python and software-engineering fundamentals with practical experience building LLM applications, retrieval pipelines, AI agents, evaluation frameworks, and API-based AI services.

The engineer should be able to take an AI use case from problem definition through architecture, implementation, evaluation, and deployment while considering accuracy, reliability, security, latency, and cost.

## 1. Generative AI & LLM Applications

Assess understanding of:

- Large Language Model fundamentals
- LLM capabilities and limitations
- Context windows and tokens
- Embeddings
- Hallucination
- Prompt engineering
- Structured outputs
- Commercial and open-source LLM integration

## 2. Retrieval-Augmented Generation

Assess the candidate's ability to reason about an end-to-end RAG pipeline including:

- Document ingestion and preprocessing
- Chunking strategies
- Embeddings
- Vector databases
- Semantic retrieval
- Metadata filtering
- Keyword/BM25 retrieval
- Hybrid retrieval
- Reciprocal Rank Fusion (RRF)
- Reranking
- Context construction and augmentation
- Grounding
- Hallucination reduction

The candidate should be able to explain not only individual components but also architectural trade-offs between alternative retrieval strategies.

## 3. Agentic AI

Assess understanding of AI systems capable of using tools and executing multi-step workflows.

Important concepts include:

- Tool/function calling
- Routing
- Planning
- State management
- Memory
- Workflow orchestration
- Human-in-the-loop patterns
- Error handling and recovery
- Multi-agent architectures

Relevant technologies may include LangChain, LangGraph, LlamaIndex, AutoGen, CrewAI, or comparable frameworks.

Knowledge of Model Context Protocol (MCP) and external tool integration may also be assessed.

## 4. AI Evaluation

Assess the candidate's understanding of systematic AI evaluation, including:

- Golden evaluation datasets
- Retrieval evaluation
- Precision@K
- Recall@K
- Ranking and retrieval metrics
- RAG evaluation
- RAGAS or similar frameworks
- Faithfulness
- Groundedness
- Answer relevance
- LLM-as-a-Judge
- Agent/tool evaluation
- Regression testing

The candidate should understand how evaluation results can be used to compare prompts, retrieval strategies, models, and system architectures.

## 5. Python & AI Application Engineering

Assess:

- Python fundamentals
- Modular and maintainable application design
- REST APIs
- FastAPI/Flask concepts
- Database and external API integration
- Structured and unstructured data
- Git
- Testing
- Logging
- Configuration management
- Error handling

## 6. AI System Design

Assess whether the candidate considers:

- Scalability
- Reliability
- Latency
- Token/model cost
- Caching
- Observability
- Failure handling
- Data privacy
- Security

The candidate should be able to reason about architectural trade-offs rather than merely name technologies.

## 7. Deployment & LLMOps

Assess general understanding of:

- Docker
- Cloud platforms
- CI/CD
- Application and model monitoring
- Logging and tracing
- Prompt/model/version management
- Kubernetes concepts
- MLOps/LLMOps

## 8. Responsible & Secure AI

Assess understanding of:

- Hallucination
- Prompt injection
- Sensitive-data exposure
- Insecure tool execution
- Excessive agent permissions
- Guardrails
- Input/output validation
- Access control
- Human oversight

The InterviewGap AI assessment should organize questions and scoring around these competency groups:

1. **Python & Software Engineering**
2. **AI/ML and LLM Fundamentals**
3. **Prompt Engineering & LLM Application Development**
4. **Retrieval-Augmented Generation**
5. **Agentic AI & Orchestration**
6. **AI Evaluation**
7. **AI System Design**
8. **Deployment, LLMOps & Observability**
9. **AI Security & Responsible AI**
10. **Problem Solving & Technical Communication**

# Assessment Principle

The candidate's resume provides context but should not be treated as proof of competency.

Interview questions should establish demonstrated knowledge and practical reasoning.

For each assessed competency, InterviewGap AI should capture:

- Question
- Candidate answer
- Expected concepts
- Retrieved evaluation evidence
- Score
- Concepts demonstrated
- Concepts missing
- Evaluation reasoning

The final competency scores and missing concepts should feed the post-interview gap analysis and personalized learning-resource recommendation pipeline.
